# Contracts: INTERNAL DRAFTS

> ⚠️ **These are working drafts written to capture how we want to work. They are not legal advice and have not been reviewed by a lawyer.** Before first use, have a Malaysian advocate & solicitor review and adapt them (Contracts Act 1950, PDPA 2010 and 2024 amendments, Sales and Service Tax, stamp duty). Until then, don't send them to clients as final.

| File | What it is | When it's signed |
|---|---|---|
| `nda-template.md` | Mutual NDA | Before discovery, if the client wants one |
| `msa-template.md` | Master Services Agreement: the umbrella terms | Once per client, with the first SOW |
| `dpa-template.md` | Data Processing Agreement (PDPA) | Whenever we touch personal data |
| `../../delivery/sow/sow-template.md` | Statement of Work: one per project | Each project |

**How they fit:** MSA (general terms) + SOW (project scope, fees) + DPA (personal data) + NDA (confidentiality before the MSA exists; the MSA's confidentiality clause supersedes it once signed).
